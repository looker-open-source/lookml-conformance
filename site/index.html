02Why it matters

Case study · l04 · lineage

Resolve LookML differently, and lineage points at a different table.

A refinement moves orders to a cleaned table. Looker reads it; two catalogs trace the raw one, so dropping the cleaned table looks safe in their lineage.

# views/orders.view.lkml
view: orders { sql_table_name: raw.orders ;; }
# views/orders_refinements.view.lkml
view: +orders { sql_table_name: analytics.orders_clean ;; }
# views/orders_rollup.view.lkml
derived_table: { sql: SELECT … FROM ${orders.SQL_TABLE_NAME} ;; }

“in most cases a refinement will override the original settings of an object” lookml-refinements
node-lookml-parser builds no lineage, so l04 does not apply to it. Open case l04

Impact analysis misses dependencies. Change or drop the cleaned table and the catalog shows nothing built on it.

1Write an adapter

from pathlib import Path

from my_tool import load_project
from lookml_conformance.adapter import Adapter
from lookml_conformance.adapters import kit
from lookml_conformance.protocol import ModelOutput


class MyToolAdapter(Adapter):
    name = "my-tool"
    distribution = "my-tool"

    def resolve(self, project: Path) -> dict[str, ModelOutput]:
        resolved = load_project(project)
        return {
            model.name: ModelOutput(views={
                view["name"]: kit.view_output(view)
                for view in model.views
            })
            for model in resolved.models
        }


if __name__ == "__main__":
    raise SystemExit(MyToolAdapter.main())

lookml-conformance new-adapter my-tool writes this file. Not Python? Print the JSON protocol.

2Add a workflow

# .github/workflows/lookml-conformance.yml
on: [pull_request]
jobs:
  conformance:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.12" }
      - uses: actions/checkout@v4
        with:
          repository: josephaxisa/lookml-conformance
          path: conformance
      - run: pip install . ./conformance
      - run: lookml-conformance run --name my-tool
               --command "python $GITHUB_WORKSPACE/my_adapter.py"
        working-directory: conformance

The job fails when a case your tool supports differs from Looker.
